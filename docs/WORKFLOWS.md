# 制作与恢复流程

## 贴图

1. 从资源包下拉框选择 PP，选择“独立图片”或模型内嵌贴图。
2. 按名称、分辨率筛选；“提取筛选”包含其他分页的全部匹配项。
3. PNG 导出保留透明通道；原始格式按目标 BMP/TGA 保存。导出目录同时包含清单和 ZIP。
4. 使用绘图软件重绘。导入新图或包含清单的文件夹。导入只保存待写入文件。
5. 默认复用原 Alpha；宽高比不一致时拒绝。BMP 按 RGB 保存，TGA 保留 RGBA。
6. “待写入”模式的 PNG 导出包含复合后的 Alpha；其他原图相关导出取原资源。
7. 核对原图、拖动对照、差异图和放大细节，再写入或导出贴图补丁。

导入上限为 8192 边长、3200 万像素。分辨率筛选根据当前资源包尺寸，待写入的放大尺寸不会改变当前筛选。

## 模型

1. 准备资源从当前 AHM05_01.pp 提取脸部、刘海与后发模型。源包准备前后哈希一致才更新预览缓存。
2. 原版即当前提取基准。可以包含之前装过的贴图或几何修改，不等于发行版原始游戏。
3. 选择平滑、膨胀或收缩。平滑使用强度、迭代次数与位移上限；膨胀/收缩使用强度作为法线偏移量，并受位移上限约束。
4. 候选只写入 `workspace/models/candidates`。面、UV、权重、骨骼、材质、贴图均保持；只允许相应头发顶点位置、法线和边界框改变。少于 50 顶点的网格与特殊 `_11` 材质会跳过。
5. 查看候选报告、位移热力图和原版红色轮廓。热力图按各网格相对位移显示，不同网格颜色不代表相同绝对位移。
6. 安装前检查候选哈希、原始哈希、当前游戏模型、结构合同、游戏关闭状态。检查后点击安装仍会再次验证。
7. 安装只替换当前选择的模型，不自动应用整批候选。推荐候选集可通过 CLI 逐个指定或批量选择 ID。

## 混合修改与恢复

贴图与模型可能写同一 PP。同包还有待写入贴图时，模型安装会拒绝。先处理贴图，然后准备当前模型并生成候选。

模型安装采用当前资源包作为备份和重建基准，保留其他成员。已生成候选遇到当前模型变化时，需要重新生成，防止覆盖新贴图。

每次安装生成一份完整 PP 备份。贴图与模型在同一记录列表中显示；连续修改同包应按最新到最旧恢复，后续外部修改会阻止直接覆盖恢复。

## ComfyUI

原 Alpha 合成：将 `homemate_workshop/comfyui/restore-original-alpha.json` 导入自己的 ComfyUI，设置原透明 PNG 与生成 RGB PNG。节点版本须支持模板中的内置 Alpha 合成节点。

头发实验模板见 `homemate_workshop/comfyui/README-hair-texture-qwen.md`。PNG 转换工具要求显式指定 ComfyUI 输入目录；不包含个人安装路径。模板依赖的模型、自定义节点需要使用者自行准备。模板保留为实验样品，不保证生图能保持 UV 结构。
