# 御宅伴侣素材工坊：Windows 便携版

适用：Windows 10/11 x64。程序已自带 Python、Pillow、NumPy 和启动器，不需要安装 Python、运行 pip 或修改配置文件。

## 第一次使用

1. 将整个 ZIP 解压到普通可写文件夹，例如“下载”或自建的工具目录。请完整保留 _internal 文件夹。
2. 双击“素材工坊.exe”。
3. 在启动窗口点击“游戏目录”的“选择…”，选择自己的游戏根目录（其中应有 data/*.pp）；也可直接选择 data 目录。
4. 如果游戏 data 目录中已有 PPExtractor0.6.2.exe，启动器会自动找到。否则点击“解包工具”的“选择…”，选择自己准备的同名工具。工具不会随本包分发。
5. 点击“启动并打开工坊”，在默认浏览器中使用。目录选择会自动保存，下次启动自动打开。

程序会检查空闲端口，默认从 8765 开始；无需自己配置端口。它仅在本机运行，不要求 GitHub 账号或联网登录。

## 使用与退出

- 浏览器页面关闭后，启动窗口仍会显示服务状态，点击“重新打开页面”即可返回。
- “停止工坊”会停止当前服务；关闭启动窗口会等待当前任务完成并退出。正在编码、导出或安装时请等待完成。
- 重复双击 EXE 会打开已有工坊，不会再启动第二份后台服务。
- 写入游戏或恢复资源包前，完全退出游戏。先查看待写入贴图或模型候选，再确认安装。

## 数据和更新

首次运行会在 EXE 同级生成 userdata 文件夹：

userdata/settings.json：已选择的游戏和工具位置。
userdata/workspace/textures：贴图缓存、待写入、导出和备份。
userdata/workspace/models：模型预览、候选和报告。
userdata/logs：启动与错误日志。

请保留 userdata，尤其是其中的 backups。更新时关闭旧工坊，将新版本解压到新文件夹，再把旧 userdata 完整复制到新 EXE 同级后启动。不要在游戏运行或工坊仍有任务时搬动数据。

若程序目录不可写，启动器会使用当前用户的本地应用数据目录 HomeMateAssetWorkshop。实际保存路径始终显示在启动窗口，可以点击“打开数据目录”。

有待写入内容或备份时，切换到另一份游戏会被拒绝。请为另一份游戏另建便携目录，保留原有备份。

## 常见问题

找不到游戏：选择包含 data 文件夹的游戏根目录，或直接选择 data；data 内须有 PP 资源包。

找不到解包工具：需要自行提供 PPExtractor0.6.2.exe。便携版包含运行环境，不包含游戏资源和这个外部程序。

窗口提示已有实例：切换到已打开的启动器。浏览器关闭不代表服务已经退出。

启动失败：点击“查看日志”。反馈时附上工具版本、错误文字、重现步骤和脱敏后的日志；无需上传完整游戏资源、备份或令牌。

移动目录后失去游戏位置：重新选择当前游戏和工具路径；旧的配置和备份不会自动删除。
